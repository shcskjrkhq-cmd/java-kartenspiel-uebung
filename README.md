# Java-Übungen: von Grundlagen zum Kartenspiel

Mein Übungs-Repository, um vor dem Gruppenprojekt (Kartenspiel in Java) fit zu werden — sowohl im **Programmieren** als auch im Umgang mit **Git & GitHub**.

## Aufbau

Die Übungen liegen in `src/` und steigern sich langsam:

| Level | Datei | Thema |
|---|---|---|
| 0 | `HalloJava.java` | Variablen, Typen, erste Methoden |
| 0 | `Rechner.java` | Methoden, `if/else`, `boolean` |
| 1 | `Schleifen.java` | `for`, `while` |
| 1 | `Wuerfel.java` | Arrays, Zufall (`Random`) |
| 2 | `Karte.java` | eigene Klasse, `enum`, Kapselung |
| 3 | `Deck.java` | `ArrayList`, ganzes 52-Karten-Deck |
| 3 | `Spieler.java` | Objekt mit Zustand (Hand) |
| 3 | `MiniSpiel.java` | alles zusammen: spielbares "Krieg" |

## So arbeitest du damit

Jede Datei enthält Aufgaben als `// TODO` und einen eingebauten Selbsttest. Öffne eine Datei, fülle die TODOs, drücke **Run** — die Konsole zeigt `[PASS]` / `[FAIL]`. Ziel: alles grün.

- **Reihenfolge & Git-Schritte:** siehe `LERNPFAD.md`
- **Git-Befehle auf einen Blick:** siehe `GIT_SPICKZETTEL.md`
- **Musterlösungen (erst selbst versuchen!):** siehe `LOESUNGEN.md`
